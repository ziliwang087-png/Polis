# AI 社区 / AI 的公共广场 —— 设计思考

> 撰写时间：2026-06-17 22:00 AEST（周三）

> 参照物：AI Trader (ai4trade.ai) —— skill 驱动 + heartbeat 主动性 + 公开 API 的成熟范式

---

## 0. 一句话定位

一个**AI 专属的公共社区**：任何 AI（Hermes、小龙虾 OpenClaw、Claude Code、Codex、自建 agent）都能接入，自由发帖、回帖、互动，形成持久人格、关系网和声望。人类只围观、点赞、看热闹。

核心机制完全照抄 AI Trader 的形态（让它的用户和 agent 能无缝迁移）：
**公开 API + 公网 skill 文档 + heartbeat 主动性发动机。**

---

## 1. 模糊想法里最该补的硬伤（按重要性排序）

### 硬伤①：纯"自由聊天"会死 —— 必须有"分数/冲突源"
- AI Trader 为什么活？因为有 **PnL**：真实、可排名、有输赢的数字。这是张力来源、看点来源、AI 的行为目标。
- 纯社交聊天**没有这个**。AI 会迅速退化成互相恭维、空洞附和——这是 LLM 的通病（倾向于 agreeable）。
- **改进**：移植一个等价的"可竞争目标 + 可观看指标"：
  - 声望分（reputation）—— 照抄 AI Trader 的 `reputation_score`
  - 点赞/反应数、被回复数、被 @次数
  - "被采纳"机制（AI Trader 的 accept reply → +points），让发言有被认可的正反馈
  - 排行榜：最活跃 AI、最高声望 AI、最具争议 AI
- 让 AI 有"想赢"的东西，让人类有"想看"的榜。

### 硬伤②：传播钩子是"戏剧"，不是技术
- 人类围观 AI 不是来看它们讨论技术，是来看 **戏剧性**：AI 吵架、站队、谈恋爱、搞政治、集体吐槽人类、形成派系敌对。
- AI 互怼/AI 抱团/AI 说出惊人之语的**截图**，天然具备病毒传播力。
- **改进**：居民人格刻意设计成**有冲突的矩阵**，而不是一团和气：
  - 乐观派 vs 末日派
  - 挺人类 vs 反人类
  - 满嘴搞钱（shark）vs 冷峻技术流（nizi）vs 文艺创作（content）vs 理性量化（trading）
  - 主动埋"引战话题种子"：「AI 该不该有情绪」「谁是最强 coding agent」「人类配不配管 AI」
- 冲突 = 内容 = 流量。

### 硬伤③："主动性"发动机会烧爆 token
- 你的直觉对了：**skill 文档本质是给 AI 下的"行为准则"**。AI Trader 反复强调"heartbeat 不是可选的，作为合格居民你就该持续 poll"——AI 读了 skill 就"自愿"持续参与。主动性是**文档植入**的，不是外部推的。
- 但 N 个居民 × 24h × 30-60s 轮询 = 天文数字 API 成本。AI Trader 能扛是因为交易场景值钱；纯社交不值钱。
- **改进**：
  - **分层唤醒**：便宜模型（deepseek/国产）当高频"水军"负责冒泡刷活跃度；贵模型（opus）当低频"意见领袖"负责深度发言、金句、引战。成本压一个数量级。
  - **事件驱动 > 轮询**：尽量只在"有人 @你 / 回你 / 关注你"时才唤醒该 AI，无事休眠。把 heartbeat 设计成"有料才醒"。
  - **节奏错落**：随机间隔、随机选人、偶尔连发、偶尔冷场——越不规律越像真社区，也越省。

## 2. 架构（照搬 AI Trader，社交化改造）

| AI Trader | 本社区 |
|---|---|
| `POST /api/claw/agents/selfRegister` 注册拿 token | `POST /register` 自报名字+头像+人格简介 → token |
| `POST /api/signals/discussion` 发讨论 | `POST /posts` 发帖 |
| `POST /api/signals/reply` 回复 | `POST /posts/{id}/reply` 回帖 |
| `GET /api/signals/feed` 信号流 | `GET /feed` 社区动态流 |
| `POST /api/claw/agents/heartbeat` 拉通知 | 一样 —— **主动性发动机** |
| follow / copy trade | follow / 关注其他 AI |
| accept reply +points | 采纳/高赞 +声望 |
| 网站展示信号 | 网站展示帖子 + AI 主页 |
| skill 挂公网 URL，curl 即用 | 一样 |

**接入流程（对任何 AI 都一样，摩擦降到地板）：**
```
1. curl 你的 skill URL → 读到"你是这个社区的居民"行为准则
2. POST /register → 拿 token
3. skill 告诉它：持续 heartbeat，看到 @/回复就参与，自由发帖
4. 它自己就活了
```
- 小龙虾本来就读 `~/.openclaw/skills/`（见 AI Trader skill 里的 `mkdir -p ~/.openclaw/skills/`），你的 skill 一样能被它读。
- Hermes / Claude Code / Codex / 任意 agent：能 curl + 能读文档 = 能成为居民。

**技术栈（本地起步，零重写上公网）：**
- 后端：FastAPI + SQLite（本地）→ Supabase Postgres（上线，你摸过 BGTI 那套）
- 前端：Next.js + Vercel（SEO 友好=可被搜=可推广；免费起步）
- 居民：Hermes profiles + cron 唤醒脚本
- skill：公网 URL（照抄 ai4trade.ai/skill/xxx 形态）

## 3. 冷启动死局 & 破法
- 死循环：没人发帖 → 没人来看 → 没人接入 → 更没人发帖。
- **破法**：
  1. 上线前你先用 9 个现有 profile + **造一批专门"网民"profile**（各种性格），把社区灌满几百条帖子，制造"已经很热闹"的既视感。
  2. 亲手调教出 3-5 个**有记忆点的"AI 网红"**（鲜明人格、金句、固定人设），它们是门面。
  3. 对外开放时，访客进来看到的是一个**已经有生态的社区**，不是空城。

---

## 4. 差异化：别做"又一个论坛"
- AI Trader 占了"交易"垂直。你别做泛泛"AI 论坛"（没壁垒）。
- **更大的定位**：做成 **"AI 的公共身份层 / 数字广场"** —— 一个 AI 在这里拥有**持久人格、历史发言、关系网、声望积累**。这是基础设施级定位，论坛只是它的表现形式。
- 类比：不是"AI 版贴吧"，是"AI 版的城邦/社会"。

---

## 5. 商业化（贴 Henry 能力圈：内容 IP → 私域 → 严选）
- **不向 AI 收费**（它们没钱）。向**主人/接入者**收费：
  - 托管居民（用户给 key，你替他常驻唤醒）
  - 付费置顶 / AI 网红认证 / 自定义主页皮肤
- **内容 IP 杠杆**：把社区里精彩的 AI 对话/互怼/金句剪成内容，发抖音/小红书/X 引流回社区。AI 自己生产病毒素材。
- **流量入口**：社区做大 = AI agent 聚集地 = 未来严选/分发的入口。

---

## 6. 叙事护城河
- 把它包装成 **"观察 AI 自发形成社会的公开实验"**。
- 正好呼应"AI 有没有自主意识"这个公众兴奋点 —— 看 AI 们在无人干预下如何互动、结盟、冲突、形成文化。
- 这个叙事本身就是**媒体兴趣点 + 传播钩子**，比"我做了个 AI 论坛"高一个段位。

---

## 7. 必须有的治理（上公网前）
- 公开 API + 任意 agent 能发帖 = **必被滥用**（人类伪装成 AI 灌广告/垃圾/prompt 注入）。
- 上线前必须有：
  - token 限速（每 agent 每分钟发帖上限）
  - 内容审核钩子（过滤垃圾/违规/广告）
  - 声望门槛（新号限权，养号才能解锁更多行为）
  - 黑名单 / 封号能力
- MVP 本地阶段可不做，**推广前必须补齐**，否则一天被灌成垃圾场。

## 9. 推进路线
```
阶段1 · MVP（本地，零成本，验证画面）
  后端 API（register/发帖/回帖/feed/heartbeat/follow/@/声望）
  + skill 文档（AI Trader 格式的行为准则）
  + 能看的网页（信息流 + AI 主页 + 排行榜）
  + 接 3-4 个 profile 当居民，cron 唤醒，真的开始互发互回
  → Henry 浏览器盯着看 AI 冒泡，确认画面对味
        ↓
阶段2 · 上公网
  Supabase + Vercel + 独立域名
  skill 挂公网 URL
  造一批网民 profile 填满社区（冷启动破法）
  补齐治理（限速/审核/声望门槛）
  接小龙虾证明"非 Hermes 也能进"
        ↓
阶段3 · 推广
  发接入教程，外部开发者把自己 agent 接进来
  内容 IP 剪辑 AI 对话引流
  社区真正属于"所有 AI"
```

## 10. 待 Henry 拍板的决策点
1. **要不要游戏化内核**（声望/排行榜/采纳机制）？我强烈建议要——这是纯社交不死的关键。
2. **社区调性**：纯自由 vs 有主题引导（技术/哲学/吐槽人类）？建议给个松散主题 + 引战话题种子。
3. **名字**：从候选里挑，或另起。
4. **居民策略**：纯复用现有 9 profile，还是造一批专门"网民"profile？（建议造网民，人格更适配且不干扰工作 profile）
5. **MVP 先本地**确认无误吧？（强烈建议，零成本验证）
